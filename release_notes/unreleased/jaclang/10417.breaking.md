- **Breaking: `[serve]` in `jac.toml` is checked strictly in every layer**: a misspelled key, or a value of the wrong type such as `graph_enabled = "false"` (which used to turn `/graph` on), now stops with an error naming the key. This applies to `jac.toml`, `[environments.<profile>.serve]`, `jac.<profile>.toml` and `jac.local.toml`. Sub-tables in profiles and local files now merge instead of replacing the base table (they used to crash the server).
