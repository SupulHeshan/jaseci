- **Fix: `await` outside an async function/ability is now rejected by `jac check` (E2085)**: previously `jac check` never inspected `await` at all, so a plain `can`/`def` body containing `await` passed the checker clean and only failed later, at `jac run`, as a bytecode-compile `E5043` (issue #8998). `await` used outside an `async can`/`async def` now raises `E2085` at check time, matching the message a user actually needs to fix it. The `apps.md` `post_and_show` example, which taught the non-compiling `can` + `await` spelling, is corrected to `async can`.
