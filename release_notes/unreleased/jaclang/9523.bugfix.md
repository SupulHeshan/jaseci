- **Fix: Native enum members declared without a value are distinct again**: Under the native backend, bare members such as `enum OpClass { HAS_ARG, HAS_NAME }` all lowered to `0`, so `==` held between different members and `set[Enum]` membership answered `True` for any member. A bare member now counts up like `auto()`, matching the Python backend, and an enum whose member values cannot be encoded natively (floats, tuples, objects) is reported as `E5092` where it is read instead of silently collapsing to zero (#9367).
